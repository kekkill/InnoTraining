# Почта

Users API отправляет письма через SMTP с помощью MailKit. Настройки задаются в User Secrets проекта `InnoShop.Users.Api` или переменными окружения.

```json
{
  "Mail": {
    "PublicApiUrl": "http://localhost:5081",
    "From": "",
    "SmtpHost": "",
    "SmtpPort": 587,
    "SmtpSecurity": "StartTls",
    "SmtpUser": "",
    "SmtpPassword": ""
  }
}
```

Пустые поля заполнить данными своей почты.

`PublicApiUrl` — адрес сайта в письмах. Хост, порт и режим защиты берутся у почтового провайдера. `SmtpPassword` — пароль SMTP/приложения для аккаунта из `SmtpUser`.

## Подтверждение

Регистрация и повторное подтверждение отправляют ссылку вида `http://localhost:5081/?action=confirm&token=...`. Страница вызывает `/api/v1/auth/confirm-email`, показывает результат и предлагает войти.

## Восстановление

Форма «Забыли пароль?» отправляет `/api/v1/auth/forgot-password`. Письмо содержит ссылку `http://localhost:5081/?action=reset&token=...`. Страница получает код из ссылки и показывает форму нового пароля. Форма вызывает POST `/api/v1/auth/reset-password`. После успешной смены нужно войти с новым паролем.

Коды действуют один час и используются один раз. В базе хранится хеш. Коды подтверждения и восстановления имеют разные назначения.

При ошибке SMTP API возвращает 503. Если регистрация уже сохранилась, после исправления настроек нужно использовать повторное подтверждение. Запрос восстановления также можно повторить.

Для Docker значения задаются в `.env`: `smtp_host`, `smtp_port`, `smtp_security`, `smtp_user`, `smtp_password`, `mail_from`. `users_public_url` задаёт адрес сайта в письмах.
