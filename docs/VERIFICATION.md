# Проверка проекта

```bash
dotnet restore InnoShop.slnx --locked-mode
dotnet test InnoShop.slnx -c Release
```

В проекте 20 тестов: 5 unit-тестов и 15 интеграционных. Они используют отдельные SQLite-базы и тестовый отправитель писем. Проверяются регистрация и подтверждение email, восстановление пароля, права пользователя и владельца товара, CRUD и поиск товаров, ошибки валидации и обмен между двумя API. Отдельный сценарий проверяет скрытие и возврат товаров после деактивации и активации владельца.

## Проверка через браузер

1. Запустить оба API и открыть http://localhost:5081.
2. Зарегистрировать пользователя с доступным email и открыть ссылку подтверждения из письма.
3. Войти, создать товар в «Мои товары», изменить его и проверить каталог с фильтрами.
4. Запросить восстановление и открыть из письма форму нового пароля. Сменить пароль и войти заново.
5. Войти администратором и деактивировать пользователя. Его товары должны исчезнуть из каталога. После активации возвращаются только не удалённые товары.

Для отправки настоящих писем нужен настроенный SMTP.

## PostgreSQL

Для проверки Docker выполнить `docker compose up --build -d` после создания `.env`. Оба `/health/ready` должны вернуть 200. Проверка на SQLite не заменяет запуск с PostgreSQL.
